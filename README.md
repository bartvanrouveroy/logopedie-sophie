# Logopedie Sophie – nieuwe website

Voorbeeldsite en hulpmiddelen voor de nieuwe website van Logopedie Sophie (Hasselt).

## Inhoud

| Map / bestand | Wat |
| --- | --- |
| `index.html` | Klikbare voorbeeldsite: alle pagina's, webshop met winkelmand, oefenportaal met rollen (ouder, logopedist, beheerder) en de chat die aanvragen verzamelt. Openen in een browser volstaat. |
| `wordpress/` | De echte WordPress-site: thema, plugin Sophie Oefenportaal en setupscript. Uitleg en installatie op Combell in `wordpress/INSTALLATIE.md`. |
| `wp/` | Zips en blueprint voor de WordPress-demo (via GitHub Pages). |
| `avi-pod/` | Script dat de AVI-leesboekjes en andere bundels drukklaar maakt (A5, afloop, viervoud pagina's, achterkant) voor print-on-demand via Lulu of Peecho. Zie `avi-pod/LEESMIJ.txt`. |

## Demo's

- Voorbeeldsite (één HTML-bestand): https://bartvanrouveroy.github.io/logopedie-sophie/
- WordPress-demo in WordPress Playground: https://playground.wordpress.net/?blueprint-url=https://bartvanrouveroy.github.io/logopedie-sophie/wp/blueprint.json

## Voorbeeldaccounts in het oefenportaal (HTML-voorbeeldsite)

Op de inlogpagina staan drie knoppen: **Ouder**, **Logopedist** en **Beheerder**.
Het wachtwoord maakt niet uit; als code voor tweestapsverificatie werkt elke reeks van 6 cijfers.

> De voorbeeldsite beveiligt niets en verstuurt niets. Op de echte site (WordPress + WooCommerce)
> doet de plugin *Sophie Oefenportaal* dezelfde controles op de server.
